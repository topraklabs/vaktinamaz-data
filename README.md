# vaktinamaz-data

Vakt-i Namaz uygulamasının kullandığı namaz vakti, bayram namazı ve hicri
takvim verileri.

Namaz vakti ve bayram namazı vakitleri, Diyanet İşleri Başkanlığı'nın resmî
"Awqat Salah" REST servisinden (awqatsalah.diyanet.gov.tr) alınmıştır. Servis,
düşük istek kotası nedeniyle verilerin geliştirici tarafından barındırılmasına
izin vermektedir; bu depo bu amaçla oluşturulmuştur.

Hicri takvim ay başları, Diyanet'in yayımladığı resmî dini günler takviminden
(vakithesaplama.diyanet.gov.tr) derlenmiştir.

Uygulama bu dosyaları çalışma zamanında indirir; böylece yeni yılın verisi
uygulama güncellenmeden eklenebilir. Bu depo resmî bir Diyanet kaynağı
değildir; yalnızca Vakt-i Namaz uygulamasında kullanılmak üzere barındırılır.
